# Security Policy

## Supported Versions

Only the latest released version of GameStuff Blocks is supported with security updates.

| Version | Supported |
| --- | --- |
| 1.5.x | ✅ |
| < 1.5.0 | ❌ |

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, use this repository's private vulnerability reporting:

1. Go to the **Security** tab of this repository.
2. Select **Report a vulnerability**.
3. Include as much detail as possible: the affected version, steps to reproduce, and the potential impact.

You should expect an initial response acknowledging the report, followed by an assessment of the issue and, if confirmed, a plan for a fix and disclosure timeline. Please allow a reasonable amount of time for a fix to be released before any public disclosure.

## Scope

This policy covers the GameStuff Blocks plugin code in this repository. It does not cover WordPress core, third-party themes, or other plugins.
